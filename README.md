# 🎲 大乐透玄学研究所

一个面向体彩大乐透历史开奖数据的本地分析网页。

它不会预测未来，也不承诺任何命中率；它做的是把历史号码整理成可查询、可视化、可解释、又带一点“玄学仪式感”的数据体验。

> 所有分析、趋势、评分和选号结果均仅供娱乐，不构成购彩建议。

## ✨ 项目看点

| 模块 | 能做什么 |
| --- | --- |
| 🧭 首页仪表盘 | 查看最新开奖、总期数、最新日期和数据健康状态 |
| 🔎 开奖查询 | 按期号、日期、号码查询历史开奖，检查一组号码历史上中过什么奖 |
| 📊 数据分析 | 从冷热、遗漏、结构、共现、矩阵、日历、数学纹理等角度观察历史号码 |
| 🔮 娱乐选号 | 基于分析画像生成单式或复式号码，并展示选号依据、结构摘要和趣味评分 |
| 🗂 数据管理 | 支持数据校验、导入、导出和脚本同步最新开奖数据 |

## 🧩 核心功能

### 🔎 查询与中奖检查

- 按期号、日期、号码快速检索历史开奖。
- 支持输入号码，也支持手动点选号码。
- 可将自己的号码保存到当前浏览器，下次打开查询页自动恢复。
- 可以检查一组号码历史上是否开出过。
- 按大乐透规则统计历史命中奖级。
- 可筛选只看指定奖级，默认关注一、二、三等奖。

### 📊 分析卡片

分析页支持区间切换：

```text
全部 / 近200期 / 近100期 / 近50期 / 近30期 / 近10期 / 自定义
```

目前包含的分析方向：

- 🔥 冷热号码
- 🕳 遗漏观察
- 🧱 结构分布
- 🔗 组合共现
- 🧮 号码矩阵
- 🌊 临号回声
- 📅 日历呼应
- 🧬 数学纹理
- 🪩 形态节奏
- 🎭 趣味玄学评分

每张分析卡片都尽量保持独立，方便后续继续增加、删除或改造。

### 🔮 分析驱动选号

选号页不是简单随机，而是先读取当前区间的数据画像，再生成结果。

支持策略：

- 🧭 综合罗盘
- ⚖️ 均衡形态
- 🔥 冷热混元
- 🕳 遗漏回响
- 🧬 数学纹理
- 📅 日历呼应
- 🎲 纯随机

支持设置：

- 单式 / 复式
- 生成 1 注、5 注、10 注
- 前区定胆、后区定胆
- 前区排除、后区排除
- 偏好形态：自动、偏均衡、偏热号、偏冷号、偏遗漏、偏数学纹理

每组结果会展示：

- 前区号码球、后区号码球
- 结构标签，例如奇偶、大小、三区分布
- 选号依据
- 五维趣味评分：均衡、热度、遗漏、纹理、玄学
- 一句娱乐化签文

复式模式会显示该复式包含多少注单式组合，仅作为娱乐计算。

## 🗃 数据设计

项目使用结构化 JSON 作为运行时主数据源，Markdown 只作为原始归档或导出展示格式。

| 文件 | 作用 |
| --- | --- |
| `data/dlt-draws.json` | 应用运行时使用的主数据源 |
| `data/dlt-meta.json` | 数据版本、总期数、最新期号、最新日期等元信息 |
| `dlt_history_FULL.md` | 原始归档、导入来源和 Markdown 展示格式 |

数据示例：

```json
{
  "issue": "26051",
  "date": "2026-05-11",
  "front": [1, 6, 14, 15, 17],
  "back": [2, 3],
  "source": "official",
  "importedAt": "2026-05-14T00:00:00.000Z"
}
```

号码在数据层保存为数字，展示时再格式化成 `01`、`02` 这样的两位号码。

## 🔄 更新开奖数据

日常更新只需要执行：

```bash
npm run sync:dlt
```

这个命令会从中国体彩网官方历史接口同步最新开奖数据，并从本地最新期开始自动补齐。

如果很久没有更新，可以扩大拉取范围：

```bash
npm run sync:dlt -- --limit=200
```

更新后建议校验：

```bash
npm run data:validate
```

其他数据命令：

| 命令 | 用途 |
| --- | --- |
| `npm run data:import-md` | 从 Markdown 重新生成 JSON |
| `npm run data:validate` | 校验期号、日期、号码范围和重复数据 |
| `npm run data:export-md` | 从 JSON 导出 Markdown |
| `npm run sync:dlt` | 同步最新开奖数据 |

## 🛠 开发约定

更完整的项目规范见：

```text
docs/PROJECT_SPEC.md
```

核心原则：

- 单个业务文件尽量控制在约 250 行以内。
- 分析卡片独立成文件，计算逻辑和展示组件分离。
- 页面负责组合模块，不直接写复杂统计公式。
- 新增数据必须经过校验。
- 新增核心逻辑应补充测试。

## ⚠️ 免责声明

大乐透开奖结果具有随机性。

本项目中的冷热、遗漏、结构、矩阵、日历呼应、数学纹理、玄学评分和选号策略都只是基于历史数据的娱乐化展示，不代表未来开奖倾向，也不构成任何购彩建议。
